# Jeff Goebel — IT Support & Consulting

A simple, responsive single-page website for my independent IT support and consulting services.

## About

This site provides an overview of the IT services I offer, including:

* Everyday IT support and troubleshooting
* Computer and device setup
* Systems and server support
* User accounts and access management
* Automation and process improvement
* Documentation and user training
* Remote and on-site support

## Running Locally

No installation or web server is required.

1. Download `index.html`.
2. Open the file in any modern web browser.

## Hosting

The website is completely static and can be hosted on services such as:

* GitHub Pages
* Cloudflare Pages
* Netlify
* Any standard web hosting service

Simply upload `index.html` to the site's root directory.

## Technology

The website uses:

* HTML5
* CSS3
* Vanilla JavaScript
* Inline SVG icons

There are no frameworks, databases, or external dependencies.

## Customization

Before publishing, update the placeholder contact information in `index.html` with the correct:

* Phone number
* Email address
* Business/service information
